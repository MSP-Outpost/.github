# MSP Outpost

**The free resource hub for MSPs.** Find tools, compare vendors, and run a better shop.

🔗 [mspoutpost.com](https://mspoutpost.com)

## What You'll Find
- **[MSP Tool Directory](https://mspoutpost.com)**: about 1,000 listings across RMM, PSA, security, backup, documentation and more
- **Guides**: practical how-tos for running and growing an MSP
- **Glossary**: plain English definitions of MSP terms
- **Free Calculators**: pricing, margin and staffing tools
- **MSP Events Calendar**: conferences, vendor events and meetups

## Open Resources Here
- [Awesome MSP Tools](https://github.com/MSP-Outpost/awesome-msp-tools): curated list of MSP software
- [MSP Glossary](https://github.com/MSP-Outpost/msp-glossary): open glossary of MSP terms

## Get Involved
Spot a missing tool or wrong info? Open an issue or PR, or list your tool at [mspoutpost.com](https://mspoutpost.com).
